# LLM Usage Report

During Assignment 4, the team used LLMs (Claude, DeepSeek) for:

* **CI and Testing:** Generating initial boilerplate for CI test files (unit tests, integration tests, and QRTs). All generated code was reviewed, debugged, and refactored by the team before use.
* **Code Refactoring:** Assisting with refactoring suggestions for existing modules. The team applied only those that improved readability without affecting algorithmic logic.
* **Translation and Transcription:** Providing a preliminary English translation of the manually corrected customer review transcript. The transcript itself was initially drafted via speech-to-text and thoroughly corrected by hand. The LLM translation was then proofread and refined by the team to preserve the original meaning.

All AI-generated content was reviewed and rewritten where necessary. All meaningful project decisions — including algorithm design, Sprint planning, acceptance criteria, and code reviews — were made independently by the team.
