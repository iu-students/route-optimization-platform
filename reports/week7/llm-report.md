# LLM Usage Report

During Assignment 7, the team used LLMs (Claude, DeepSeek) for:

*   **Documentation Finalization:** Assisting with updating `docs/customer-handover.md` to explicitly state the final transition statuses. Drafting boilerplate text for the final `CHANGELOG.md` release notes. The AI provided standard structural templates, which were then heavily customized, reviewed, and rewritten by the team to accurately reflect the actual repository workflow and project state.

*   **Code Debugging:** Providing minor syntax references and debugging suggestions during the final algorithm tuning (specifically for the depot departure logic and multi-run checks that closed the 2% gap on test case 4). The core mathematical logic and CP Solver integration were entirely designed and implemented by the developers.

*   **CI and Testing:** Assisting in writing and configuring CI pipeline test scripts. The AI provided boilerplate code for automated testing and linting steps, which the team then integrated, debugged, and customized.

* **Translation and Transcription:** Providing a preliminary English translation of the manually corrected customer review transcript. The transcript itself was initially drafted via speech-to-text and thoroughly corrected by hand. The LLM translation was then proofread and refined by the team to preserve the original meaning.

All AI-generated scripts, code snippets, and texts were reviewed, debugged, and rewritten where necessary by the team. The team independently analyzed the customer's transition readiness feedback, prepared the repository for handover, refined the Product Backlog, formulated acceptance criteria, and conducted all code reviews and meaningful project decisions.
