# LLM Usage Report

During Assignment 3, the team used LLMs DeepSeek, Claude, Z.ai were utilized for:

*   **CI/CD and Documentation:** Checking the syntax for the Lychee link-checking script (`link-check.yml`) and generating basic boilerplate text for GitHub issue templates and the `Definition of Done`, which were then heavily customized by the team. Llm also helped to format the text in md format from Google docs.
*   **Code Implementation:**  Assisting in writing the code for the experimental CP Solver branch. Howewer, the core algorithmic logic  was entirely designed and implemented by the developers.
*   **Translation and Transcription:** Providing a preliminary English translation of the manually corrected customer review transcript. The transcript itself was initially drafted via speech-to-text and thoroughly corrected by hand. The LLM translation was then proofread and refined by the team to preserve the original meaning.

All AI-generated scripts, code snippets, and texts were reviewed, debugged, and rewritten where necessary by the team. The team independently analyzed the customer's feedback, refined the Product Backlog, planned the Sprint, designed the architecture, formulated acceptance criteria, and conducted all code reviews and meaningful project decisions.
